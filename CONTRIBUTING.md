# Contributing to Whiteboard

Use Node.js 24, run `npm ci`, then start the app with `npm run dev`.

Before submitting a pull request, run `npm run verify`. Keep changes focused and add a
regression test when fixing behavior that could break again. For canvas or menu changes,
check the interaction in a browser, including a small window and different zoom levels.

For a bug report, describe what you expected, what happened, and the steps needed to reproduce
it. Include your operating system and whether you used the browser or desktop app. Use a
sample board when possible and remove private content from anything you share.

For a larger feature, open an issue first to discuss the intended behavior. Contributions are
made under the project's [MIT license](LICENSE).
